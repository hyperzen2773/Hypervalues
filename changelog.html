Changelog

3.11 - 11.11.2026

  • The closest ideologies are now ranked by a Bayesian model instead of the neural network. For each ideology it asks how likely someone who holds it would be to give your answers: each value you answered is compared with the ideology's stance, a value the ideology never mentions counts against it (less so when the ideologies close to it do mention that value), and an ideology that lists few values and matches all of them beats one that lists many. Because it is not known how far a person strays from an ideology, the model averages over several amounts instead of picking one.
  • The number next to each ideology is now its probability, for example 84.3%: its likelihood divided by the sum over all ideologies. The order and the number come from the same calculation, so they always agree. The probability is relative to the other ideologies, so answers that fit none of them still give the best one a share. The rings and the scores of single values on the ideology page are unchanged, from -1 to +1.
  • A value you leave at 0 now counts as a neutral answer, which counts against an ideology that holds that value strongly and does not affect one that never mentions it. A value you did not add is not an answer.
  • Rhine Capitalism is now held by Progressive Corporatism, Austro-Corporatism, the Nordic Model, Social Gaullism and Reform Gaullism, whose definitions describe partnership between workers, employers and the state.
  • FairTax, Instrumentalism and Posthumanism are removed from the quiz until an ideology holds them: no definition says they do, so choosing them changed nothing.
  • There is nothing to train any more: adding an ideology or a value to data.js is enough, and the weights file is gone. The old model and its training files are kept in archive/embedding-model.
  • New tools/check_scoring.js checks the data, the quiz and the ranking after a change: node tools/check_scoring.js.
  • The numbers of the model were chosen with simulated answers, not answers from real people.

3.10 - 08.11.2026

  • New Download image button between Clear all and Back to menu. It saves your whole result as two sharp pictures, one for phones (1080 x 1920) and one for computers (1920 x 1080), with the best match, the next closest ones and every value you added, in the font of the site. All value names are the same size, and so are all the numbers. The menu next to the button makes the pictures 2 or 3 times bigger with the same proportions. Your browser may ask to allow two downloads.

3.9 - 08.11.2026

  • The closest ideologies are now ranked by an embedding model. A small neural network turns your answers into a point of 32 numbers, each ideology is a point built from its definition, and the ones closest to you rank first. The score is how likely each ideology is given your answers: 0 means no better than chance, +1 means certain. An ideology has no numbers of its own, so a new ideology needs only its definition, no training. It is trained on simulated users generated from the definitions, because there is no real data. On simulated users it finds the right ideology first in 97% of cases when every category is answered (91% for the Naive Bayes model before it), 59% when only about half are (55% before) and 86% when many related values are picked (67% before). With a lot of noise or two ideologies mixed it is only a little better (46% against 43%, 52% against 48%), and with a single value answered it can pick oddly. This is not a fair test, since the model is trained on the same kind of users. If the model fails to load, the plain similarity between your answers and the definitions is used.
  • Every one of the 237 ideologies now lists the values its own definition mentions, from -1 (it opposes the value) to +1 (it matches it); values it never mentions are left out. The old value sets are no longer used to score.
  • Rewrote the description of all 237 ideologies as a plain definition of what each one holds and opposes, in terms its own supporters would accept, without history or labels from outside. Italian Fascism, National-Socialism and Neo-Nazism, which had none, now have one.
  • The ideology page lists the values its definition mentions, by category, each with the ideology's own score. Coming from the results page, the rings still show how each value compares with your answers.
  • Fixed the quiz: choosing a value you had already marked neutral or opposite now sets it to +1 instead of doing nothing; an unknown category in the link goes back to the results page instead of showing a blank page; if the questions cannot be loaded, a message and a Back button are shown.
  • Fixed the page icon, which pointed to a missing file with a wrong type. A placeholder icon is in place until there is a real logo.
  • Known gaps: Fair Tax and Posthumanism are held by no ideology, so choosing only one of them finds no match; 82 ideologies have less certain definitions with few scores.

3.8 - 02.11.2026

  • Changed again how the closest ideologies are chosen. Each value set of an ideology is now scored by how likely someone holding it would be to give your answers: matching a rare value counts for more, and a different answer lowers the score by a similar amount whatever it is. Ideologies with several value sets are neither helped nor hurt by it, and ties go to the ideology with more matching values. In tests that changed a few answers of known value sets, the original ideology was found more often than before.
  • Scores now run from -1 to +1, where 0 means no evidence either way.
  • Rewrote all the questions and answers. The 128 values are the same, but the quiz is shorter (52 questions instead of 71, about 19 per quiz), every value is reached after the same number of questions in its category, each answer says one thing in a neutral tone, and each category asks only about its own topic.
  • The results page is now the main page of the quiz. After Continue it shows the nine categories, each with an "Add new value" button, and your closest ideologies below them, updated every time you add or remove a value or move a slider. It replaces the 3x3 table of icons and the "Show my results" step. "Clear all" starts over.
  • "Add new value" asks the questions of that category and brings you back to the list once you get a value. "Skip this category" and "None of these fit" are gone: a category you do not touch is ignored. The back button is now a regular answer button at the end of the answers.
  • You can add several values per category. Click a value to see its description and a slider from -1 (opposite) to +1 (match); a new value starts at +1. The more values you add, the less each one says, so adding values you do not hold does not help. A value you do not add counts against it, and a value you mark opposite counts against it even more. How much more is an assumption, since there is no data to measure it.
  • The ideology page shows each value set as a list of the nine categories instead of a 3x3 table, still browsed with the arrows.
  • The categories are now ordered by how much each one narrows down the ideologies, on the results, values and ideology pages: economics, technology, culture, social control, authority, foreign policy, nation, territorial organization, resource management. The values in each category on the results page are ordered by how much they match you.
  • The layout is rebuilt for phones and wide screens: on wide screens the lists use two columns, and buttons no longer keep their hover look after a tap.
  • The closest ideologies are shown as outlined bubbles in the ideology's color, like the original "Next closest match", without the rank circles and the arrow.
  • The results page no longer looks for an exact match. The best-scoring ideology is shown on top, and the next three below it, each with its score instead of the number of matching values.
  • Sub-groups and the clashes between them are removed, since the score no longer uses them.
  • On the ideology page, the ring around each value now fades from dark red (-1, opposite) through gray (0) to dark green (+1, match), using the same score as the ranking. Matching a rarer value gives a stronger green.
  • Long names now wrap like the original: a line breaks between words or at a hyphen when that is enough, and a word is only broken inside when it cannot fit on a line by itself. This applies to the closest ideologies and to value names on the results, values and ideology pages.

3.7 - 31.10.2026

  • The results page now shows your three closest ideologies instead of one. Opening any ideology (from the results or the ideology list) shows its name, its values laid out by category and its description. Use the arrows to browse its other value sets. When opened from your results, each value is ringed by how it compares with yours: green for the same or a close value, yellow to red for clashes (from mild to extreme) and gray for unrelated.
  • Reworked how the closest ideologies are chosen: a clashing value now lowers the score by an amount that depends on how serious the clash is, instead of removing the ideology completely.
  • Rarer values now count for more, ideologies with several value sets no longer get an unfair advantage, and ties go to the ideology you match more closely.
  • Added 23 new pairs of clashing sub-groups, and some values (for example Neocorporatism) now belong to more than one sub-group.
